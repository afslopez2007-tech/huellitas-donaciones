# Huellitas del Cauca - Portal de Gestión de Donaciones

Aplicación web frontend para registrar y organizar las donaciones de un refugio animal.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño visual adaptable.
- `script.js`: registro, búsqueda, edición y eliminación de donaciones.

## Funciones
- Catálogo de necesidades.
- Formulario con validación.
- Registro de donante, categoría, cantidad, estado y fotografía.
- Vista de donaciones registradas.
- Búsqueda y filtros por tipo y estado.
- Edición y eliminación de registros.
- Cambio del estado de una donación.
- Resumen de cantidades.
- Guardado en `localStorage` del navegador.

## Cómo ejecutar
1. Clona o descarga el repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` con Live Server.

También se puede publicar con GitHub Pages desde la rama `main`, seleccionando la carpeta raíz.

## Tecnologías
HTML5, CSS3, JavaScript, Bootstrap 5 y localStorage.

## Nota
Es una aplicación frontend: los registros se guardan en el navegador utilizado y no en una base de datos compartida. Se necesita conexión a internet para cargar Bootstrap desde su CDN.
